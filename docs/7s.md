# 学生宿舍7S管理标准

为了营造文明卫生整洁的宿舍环境，按学校“7S”管理要求定制宿舍内部管理标准如下；请同学们认真按标准执行。

## 宿舍内物品摆放标准：
1. 被子居中叠放在靠阳台的床的一端，被口朝门，枕头放在被子上，床上禁止放其他物品，禁止晾挂衣物。
2. 书包、行李袋、行李箱按照高到低、大到小的顺序竖直摆放在指定空余位置，如宿舍无空位，则按照大小放置在床底置物架上。
3. 鞋子摆放在床底，鞋跟朝外。
4. 开水瓶、水杯，把手朝外，统一放置在宿舍窗户下的墙壁边，一字摆开。

## 阳台物品摆放标准：
1. 衣服有序的晾晒在阳台的三根或四根晒衣链上：上衣晾在靠里的第一条链上，内衣、内裤、袜子晾在中间第二条链上左端，毛巾晾在中间第二条链上右端，裤子晾在靠外的第三条链上。 
（女生：毛巾晾在中间第二条链上，内衣、内裤、袜子晾在中间第三条链上。）
2. 牙膏、牙刷摆放在牙缸内，牙膏在里侧，牙刷在外侧，牙刷面向上在牙缸内与牙膏紧靠一起，统一摆放在盥洗池上方的架子上，把手朝右与牙缸搭在一起。
3. 洗漱用品，洗衣粉、洗发水、香皂等日用品有序的摆放在盥洗池下方右侧的置台上。
4. 水桶按大小垒放，平均垒放成两垒，垒好后在阳台栏杆下按一字摆放，脸盆按大小垒放在水桶上，脸盆内禁止放置其他物品。
5. 拖把、扫把 、簸箕、晾衣棍统一放在阳台指定角落。

## 安全与节约标准：
1. 请同学们在睡觉时头朝护栏方向，以免发生坠床意外！
2. 不得私拉电线，不得放置管制刀具和易燃易爆违禁品。
3. 不得使用明火和电热棒及其他电器设备。
4. 洗澡时，严禁戏水、追逐打闹。
5. 节约用水用电，最后一人离开宿舍时关水关电锁好门窗，将个人贵重物品妥善保管好，以防丢失！

## 五线四净五洁要求：
1. 摆好五条线：毛巾、衣裤悬挂一条线；鞋子放置一条线；牙具摆放一条线；水瓶排列一条线；水桶、脸盆放置一条线。
2.保持四个净：地面干净（无垃圾、杂物、积垢、水渍、脚印）;门窗干净（门、门框、窗框无灰尘，门上无乱写乱画，窗户干净透明）；墙壁干净（墙壁、天花板、无灰尘、无蜘蛛网、无脚印、无污迹）；电器干净（风扇、灯管、开关盒、无灰尘、无蜘蛛网）。
3. 保持五个洁：牙具水桶脸盆内外清洁；水瓶外壳清洁；鞋子行李袋/箱清洁；床上用品清洁；盥洗池、便池、卫生工具清洁、无积垢。
