# 数据预览

本页对应系列题中的 **题 1**,目的是把 `house_module.csv` 读进来,并打印前 10 行,直观感受一份「二手房房源数据」长什么样、字段有哪些、是否存在空值或异常。

## 题目描述

读取同目录下 `house_module.csv`,在控制台输出前 10 行数据,字段包括 `市区`、`小区`、`户型`、`朝向`、`楼层`、`装修情况`、`电梯`、`面积(平方米)`、`价格(万元)`、`建造年份`。

## 参考代码

```python
import pandas as pd

df = pd.read_csv('house_module.csv')
print(df.head(10))
```

## 思路拆解

1. `import pandas as pd`:把 pandas 这个数据处理库导入,并取别名 `pd`(约定俗成的写法)。
2. `pd.read_csv('house_module.csv')`:读入 CSV,得到一个二维表对象 `df`(在 pandas 里叫 `DataFrame`)。
3. `df.head(10)`:取出前 10 行;若不传参数,默认取前 5 行。
4. `print(...)`:把结果输出到控制台,方便肉眼检查字段名与数据格式。

::: info 字段含义速览
- **面积(平方米)**:套内建筑面积,后续清洗时会过滤空值和异常小的值。
- **价格(万元)**:总价,后续会按均价过滤「豪宅」型异常值。
- **电梯**:文本字段(`有电梯` / `无电梯`),存在空值,后续用 `dropna` 清理。
:::

## 常用辅助命令

预览之外,几个常和 `head` 搭配使用的命令,适合在探索数据时一并记忆:

```python
df.shape      # (行数, 列数)
df.columns    # 所有列名
df.dtypes     # 每列的数据类型
df.info()     # 列名 + 非空值数量 + 类型,综合摘要
df.describe() # 数值列的统计信息(均值/分位数/极值)
df.isnull().sum()  # 每一列的空值数量
```

## 易错点

- **路径写错**:`read_csv` 的路径是相对于运行 Python 时的「当前工作目录」,而不是相对于 `.py` 文件本身。建议把代码与 CSV 放在同一目录,或在 `read_csv` 中写绝对路径。
- **中文乱码**:CSV 通常是 UTF-8 编码,如果出现乱码可加 `encoding='utf-8-sig'`(带 BOM)或 `gbk`。
- **忘记 `print`**:在 Jupyter / IPython 之外,只写 `df.head(10)` 不会自动打印结果,需要套上 `print`。
