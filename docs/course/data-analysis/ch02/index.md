# 第 2 章 pandas 快速入门

## 栏目简介

本栏目对应「pandas快速入门」章节的全部讲义内容,围绕 pandas 数据分析入门展开。内容来源于 GitBook 版讲义,这里整理为 Markdown 形式,方便在线查阅与复习。建议按顺序阅读,并在每页代码示例处打开 Jupyter Notebook 实际运行验证。

::: tip 学习准备
在开始本章之前,请确认已安装 Python 3.9 及以上,并通过 `pip install pandas` 安装 pandas。
:::
