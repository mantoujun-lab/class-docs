## 栏目简介

本栏目是「数据分析讲义」的第 6 章,主题是 **pandas 综合案例**。前面几章分别讲解了 pandas 基础、数据清洗与数据可视化,本章把这些知识串起来,通过三个贴近真实业务的案例,完整走一遍「读数据 → 清洗 → 分析 → 可视化 → 业务解读」的流程:

- **案例 1:Appstore 数据分析**——以 App Store 应用商店数据为例,做描述性数据分析,涵盖数据概况、单变量分析、业务数据可视化与业务解读。
- **案例 2:优衣库销售数据分析**——以优衣库门店销售数据为例,使用 `pivot_table` 透视表与 seaborn 图表完成不同产品、顾客偏好、时间维度与营收成本关系的业务解读。
- **案例 3:RFM 用户分群**——基于会员订单数据,使用 R/F/M 三个维度对会员做价值度评分与分群,并用 pyecharts 绘制三维柱形图展示分群结果。

学完本章,你将能够独立完成一个完整的数据分析任务,从原始数据到业务结论。

## 学习建议

- 按 **6.1 → 6.2 → 6.3** 的顺序学习,案例难度逐步提升,前两个案例偏描述性分析,第三个案例引入用户价值度建模思维。
- 案例代码均可直接复制运行,但建议先理解分析思路再敲代码:先想清楚「要回答什么业务问题」,再决定「用什么图表、做什么计算」。
- 三个案例用到的数据集不同(Appstore、优衣库、会员订单),运行前请确认数据文件路径与字段是否与讲义一致。
- RFM 案例涉及 `pd.cut` 分箱与 pyecharts 三维绘图,如果对这两个知识点不熟,可先回到[第 5 章数据可视化](/course/data-analysis/ch05/)复习 pyecharts 部分。
