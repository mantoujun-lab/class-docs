## 如何提交笔记

1. 在 `docs/course/` 下按学科新建 Markdown 文件,例如 `docs/course/fundamentals.md`
2. 按 [Markdown 写作](/guide/writing) 的规范编写内容
3. 在 `docs/.vitepress/config.mts` 的 `/course/` 侧边栏中登记新页面
4. 按 [参与共建](/guide/contributing) 的流程提交 Pull Request
