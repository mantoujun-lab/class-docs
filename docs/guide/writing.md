# Markdown 写作指南

本指南面向刚开始用 Markdown 写笔记的同学,介绍在本文档站中最常用的语法。掌握这些已经足够写出结构清晰、排版整洁的笔记。

## 基础语法

### 标题

用 `#` 表示标题层级,`#` 个数越多层级越深。一般一篇笔记用到三级标题即可。

```md
# 一级标题(页面主标题,通常自动生成,正文少用)
## 二级标题
### 三级标题
```

### 强调

```md
**加粗文本**
*斜体文本*
~~删除线~~
```

### 列表

```md
- 无序列表项
- 无序列表项

1. 有序列表第一项
2. 有序列表第二项
```

### 链接与图片

```md
[链接文字](https://example.com)
![图片描述](/图片路径.png)
```

## 代码块

用三个反引号包裹代码,并在开头声明语言以启用 **语法高亮**:

````md
```js
function hello(name) {
  console.log(`你好, ${name}!`)
}
```
````

可以在语言后加 `{行号}` 高亮指定行,例如 ` ```js{2} ` 会高亮第二行,方便在讲解时圈出关键代码。

## 提示容器

VitePress 提供四种提示容器,非常适合在笔记里标出重点与注意事项:

```md
::: info
普通信息,补充说明。
:::

::: tip
小技巧,推荐做法。
:::

::: warning
需要留意的事项。
:::

::: danger
严重警告,避免误操作。
:::
```

效果如下:

::: info
普通信息,补充说明。
:::

::: tip
小技巧,推荐做法。
:::

::: warning
需要留意的事项。
:::

::: danger
严重警告,避免误操作。
:::

还可以用 `::: details` 创建可折叠的详情块,适合放长代码或附加资料:

::: details 点击展开详情
这里可以放较长的补充内容,默认折叠不占版面。
:::

## 写作小建议

1. **一篇笔记一个主题**,标题层级清晰,方便检索
2. **代码块声明语言**,让语法高亮正常工作
3. **重点用提示容器**,而不是满篇加粗
4. **图片放 `docs/public/` 下**,用绝对路径 `/文件名.png` 引用
